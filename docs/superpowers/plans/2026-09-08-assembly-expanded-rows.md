# План обновления раскрытых сборок

**Цель:** сделать состав сборки понятным продолжением таблицы товаров по образцу вложенных строк коллекций.

**Основание:** пользователь поручил составить план, передать реализацию другой модели и проверить с исправлениями. Дизайн ограничен существующим раскрытием; отдельное подтверждение не требуется.

**Архитектура:** сохранить единый `AssemblyExpandedRow` и существующие обработчики. Взять оформление из фактически используемых вложенных строк коллекций в `ProductsV2Table`, а не из неиспользуемого `CollectionExpandedRow`. Использовать плоские строки, нейтральные разделители и фон, компактную строку состава и нижнюю сводку. Desktop показывает согласованные колонки: компонент / материал / количество / общий вес / сумма. Mobile сохраняет все значения в читаемой адаптивной раскладке.

**Ограничения:** не менять БД, зависимости, расчёты модели данных, коллекции и чужие изменения. Не коммитить и не пушить. Работать поверх текущей ветки test. Использовать DESIGN_SYSTEM.md, существующие shared/ui; вся анимация через Motion. Существующее раскрытие в родителе сохранить без дополнительной анимации высоты внутри.
