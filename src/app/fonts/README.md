# Application fonts

Inter and JetBrains Mono are stored locally so development and production builds
do not depend on Google Fonts being reachable. Both variable fonts include Latin
and Cyrillic glyphs. The existing CSS variables and font assignments are unchanged.

Original files from the official Google Fonts repository:

- Inter: https://github.com/google/fonts/tree/main/ofl/inter
- JetBrains Mono: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

Both are distributed under the SIL Open Font License 1.1. Their license texts are
included alongside the font files.
