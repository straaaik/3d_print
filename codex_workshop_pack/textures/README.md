# Optional textures

Эти карты необязательны. Для чистого low-poly результата можно оставить flat PBR materials.

- `floor_concrete_albedo.png` + `floor_concrete_roughness.png`: мягкий технический пол.
- `wood_light_albedo.png` + `wood_light_roughness.png`: лёгкая текстура столешниц.

Maps 1024×1024, рассчитаны на повторение. Не применять их к моделям принтеров без необходимости.
