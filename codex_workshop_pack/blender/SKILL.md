# Blender → GLB для WebGL

Работай как технический 3D-художник. Этот skill определяет только правила работы с Blender и web-ассетами. Он не определяет конкретную сцену, дизайн помещения или бизнес-логику проекта.

## 1. Окружение

Прочитай ближайший проектный `AGENTS.md`, задачу и существующую структуру ассетов. Сохраняй рабочие решения и ручные правки. Проверь `blender --version`. Используй `bpy` и headless CLI, когда они доступны. GUI нужен для визуальной проверки или операций без надёжного API. Не устанавливай Blender или плагины без разрешения.

## 2. Структура файлов

Рекомендуемо:

```text
assets/blender/
assets/textures/
public/models/
scripts/blender/
```

Master `.blend` хранить отдельно от экспортированных `.glb`. Разрушающие операции выполнять на копии. Генераторы должны быть безопасны при повторном запуске и изменять только собственные объекты.

## 3. Масштаб и transforms

- Metric units.
- 1 Blender Unit = 1 meter.
- Проверять реальные world dimensions, origin, rotation, scale и axis.
- Для объектов, ставящихся на поверхность, origin держать на нижней опорной точке.
- Перед экспортом устранять случайный negative scale и проверять normals.

## 4. Геометрия

Приоритет: силуэт → пропорции → чистая геометрия → детализация. Не моделировать невидимые внутренние механизмы, если они не нужны с целевой камеры. Проверять duplicate vertices, flipped normals, non-manifold geometry, UV и швы. Bevel применять только там, где он заметно улучшает силуэт.

Low-poly оптимизировать с учётом расстояния камеры и количества экземпляров. После Decimate обязательно визуально проверять модель с целевой камеры.

## 5. Материалы

Использовать glTF-compatible PBR на базе Principled BSDF. Основные каналы: Base Color, Metallic, Roughness, Normal, Emission, Alpha. Не полагаться на сложные Blender-only node graphs. Не запекать направленные блики и тени в Base Color.

## 6. Текстуры

Обычно достаточно 512/1024/2048. 4K — только при реальной необходимости. Проверять UV и растяжения. Для low-poly web-сцен предпочитать небольшое число материалов и повторно используемые текстуры.

## 7. Повторение

Катушки, мебель и одинаковые объекты должны использовать linked duplicates/instances, если это уместно. Не создавать десятки уникальных мешей или материалов без необходимости.

## 8. Экспорт

Основной web-формат: `GLB / glTF 2.0`. Не использовать FBX без отдельного запроса. Перед экспортом проверить размеры, transforms, normals, UV, материалы и ненужные объекты. Экспортировать только нужные meshes и empties. GLB должен работать независимо от `.blend`.

## 9. Проверка

После экспорта открыть/импортировать GLB в чистую сцену и проверить: dimensions, orientation, origin, materials, UV и visual appearance. Успешная команда экспорта не является достаточной проверкой.

## 10. Web performance

Оценивать вместе: triangles, vertices, draw calls, materials, texture memory, GLB size и число экземпляров. Для объектов, повторяемых десятки/сотни раз, особенно важны малое число материалов и возможность instancing.

## 11. Выдача

Для каждого ассета по возможности сохранять `.blend` и `.glb`, а также кратко записывать dimensions, triangle count, materials, texture resolution и размер GLB. Не создавать UI или бизнес-логику, если задача касается только Blender.
