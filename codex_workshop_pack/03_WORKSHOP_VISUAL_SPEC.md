# Визуальная спецификация Мастерской

## Цель

Ориентир — `references/target_reference.png`: изометрическая management-game сцена в low-poly стиле, встроенная в инженерный dashboard. Не копировать чужой брендинг; сохранить визуальный язык текущего сайта.

## Композиция

- WebGL занимает основную часть страницы.
- Inspector справа: 340–380 px на desktop.
- Верхняя навигация остаётся общей навигацией сайта.
- Внутри 3D-комнаты — минимум декоративного мусора. Главные объекты: принтеры, столы/стойки, филамент.
- Дальние стены образуют L/U-образную открытую комнату без потолка.

## Default room

- 14 × 10 м.
- высота дальних стен 2.6 м;
- толщина пола 0.22 м;
- low-poly bevel на краю платформы;
- передняя сторона открыта к камере.

## Камера

Orthographic.

Стартовый ориентир:
- position ~ `[12, 13, 12]`;
- target ~ `[0, 0.8, 0]`;
- azimuth ~ 45°;
- elevation ~ 42–48°;
- подбирать orthographic frustum по container aspect, чтобы комната занимала ~80–88% доступного viewport.

OrbitControls с damping, ограниченным polar angle, умеренным zoom и pan. Не позволять смотреть снизу.

## Default layout

Зона A — прототипы, слева.
Зона B — производство, центр/задняя часть.
Зона C — материалы, справа у стеллажей.
Зона D — упаковка/выдача, ближе к переднему левому углу.

Для MVP default room: 4 длинных стола и 2 стеллажа филамента. Использовать только 2 уникальные модели принтеров, повторять их.

## Столы

- tabletop: светлое дерево;
- metal frame: graphite;
- размеры по умолчанию 3.6 × 0.8 × 0.85 м;
- 3–4 printer slots на стол в зависимости от ширины.

## Low-poly принтеры

A1-style: светлый открытый gantry, тёмная механика, небольшой экран.
P1-style: тёмный закрытый куб, прозрачная передняя панель, внутренний стол.

Не использовать логотипы Bambu Lab. Сходство — только общий тип конструкции и силуэт.

## Filament rack

Тёмный/графитовый каркас, тёплые деревянные полки или нейтральные полки. Цветные катушки создают главный цветовой акцент. Не использовать отдельные модели для каждого цвета.

## Свет

- HemisphereLight: мягкий общий свет.
- DirectionalLight: один основной ключевой свет + мягкая shadow map.
- максимум один fill.
- emissive strips под столами/полками для тёплого акцента без десятков PointLight.
- `ACESFilmicToneMapping`; output color space sRGB; renderer pixel ratio clamp 1–1.5.

## Materials

Graphite: `#171B22`, metallic ~0.45, roughness ~0.4.
Light body: `#D7DADD`, metallic ~0.1, roughness ~0.45.
Floor: `#8D9299`, roughness ~0.72.
Wood: `#B9895A`, roughness ~0.55.
Selection: `#2F7BFF`, сдержанный emissive, без сильного bloom.

## Текстуры

В папке `textures/` есть optional 1K карты пола и дерева. Для максимально чистого low-poly стиля разрешено вообще использовать только flat PBR colors. Текстуры не должны быть обязательными для работы сцены.
