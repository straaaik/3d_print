# Функциональная спецификация страницы «Мастерская»

## Назначение

`/workshop` — визуальная карта реальной мастерской пользователя. Она не создаёт новый каталог принтеров или пластика, а отображает **расположение уже существующих** сущностей сайта.

## Иерархия

```text
Мастерская пользователя
└── Комнаты
    ├── Столы
    │   └── printer slots
    ├── Стойки принтеров
    │   └── printer slots по уровням
    └── Стеллажи филамента
        └── filament slots
```

## Комнаты

Пользователь может создавать, переименовывать, менять размеры, удалять и переключать комнаты. У комнаты есть `width_m`, `depth_m`, порядок и сохранённый вид камеры. При удалении комнаты требовать подтверждение и не удалять существующие records `printers`/`filaments`; удаляется только пространственное размещение.

## Мебель

MVP типы: `table`, `printer_rack`, `filament_rack`. Мебель хранит world transform. Слоты мебели хранят local transform относительно мебели. Поэтому перемещение мебели автоматически перемещает всё, что на ней стоит.

### Table
Параметры: имя, ширина, глубина, высота, количество printer slots. Геометрия процедурная: светлая столешница + тёмные металлические ножки.

### Printer rack
Параметры: ширина, глубина, высота, количество уровней и слотов на уровень.

### Filament rack
Несколько уровней и мест под катушки. Одна геометрия катушки, цвет материала берётся из существующего `filament.color`.

## Режимы

### VIEW
- осмотр комнаты;
- поиск принтера;
- выбор принтера;
- inspector справа;
- minimap;
- переход к другой комнате.

### EDIT
- добавить мебель;
- drag мебель по полу;
- snap 0.25 или 0.5 м;
- rotate 90°;
- изменить параметры;
- удалить;
- запрещать выход за границы комнаты;
- базовая AABB проверка пересечений.

## Принтеры

Принтер выбирается из уже существующих данных сайта. Placement содержит ссылку на printer record + `visual_model_key` (`a1` или `p1`). Принтер занимает slot. Визуальная модель не является источником бизнес-данных.

При выборе принтера в 3D:
1. выделить selection marker;
2. немного сместить target камеры;
3. открыть inspector;
4. показать реальные данные принтера и его положение: room → furniture → slot.

Не показывать вымышленный progress/temperature, если проект реально их не хранит.

## Филамент

Филамент выбирается из существующей таблицы/feature сайта. Placement отвечает только за расположение. Название, вес, цена и цвет не дублируются. Визуализация катушки получает цвет из данных.

## Поиск

Поиск существующего принтера:
- если размещён — переключить комнату, выделить, сфокусировать;
- если не размещён — показать `Принтер не размещён` + действие `Разместить`.

## Статистика

Только реальные вычисляемые значения: количество комнат, размещённых принтеров, столов/стоек, свободных слотов.

## Responsive

Desktop: canvas + inspector справа. Tablet: inspector overlay. Mobile: 3D viewport + bottom sheet.
