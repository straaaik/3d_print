# Этап 4 — товары и связь с калькулятором

Это четвертый этап. Новый calculation engine/project уже существует.

Обнови Products:
1. Существующая раскрывающаяся строка -> полноценный editor всех расчетных параметров + CalculationReceipt.
2. Live preview; Save/Cancel; dirty indicator и предупреждение ухода.
3. Редактирование не списывает material и не меняет stock_quantity.
4. «Открыть в калькуляторе» переносит все поля + product ID и показывает режим «Редактирование товара: name».
5. «Обновить товар» обновляет исходный ID; «Сохранить как новый» создает новый ID.
6. Новая средняя цена filament: существующий Product не меняется автоматически. Новый Product использует current average. Для существующего предложи explicit recalc/update, но без autowrite.
7. Старые Orders остаются snapshot-ами и не меняются.
8. Проверь single и assembly товары; при необходимости адаптируй assembly без регрессии.

После этапа пользователь должен уметь полностью редактировать товар и через row, и через Calculator без дублей.
