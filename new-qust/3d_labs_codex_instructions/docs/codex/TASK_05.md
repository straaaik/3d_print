# Задача 5 — товары и редактирование через калькулятор

Расширь раздел «Товары» 3D Labs. Существующая раскрывающаяся строка товара с анимацией должна стать полноценным редактором расчета товара.

Требования:
1. В раскрытом блоке разреши менять название, принтер, конкретный вариант филамента/цвет, вес, время печати, количество/базовые параметры, ручной труд, технологический брак, дополнительные расходы, наценку, скидку, срочность и остальные параметры calculation engine.
2. Все изменения пересчитывают preview/чек в реальном времени, но в базу пишутся только после «Сохранить изменения». Добавь «Отменить изменения» и индикатор несохраненных изменений.
3. Показывай полный CalculationReceipt с той же структурой, что в калькуляторе. Формулы и отображение должны использовать общие модули, а не копии.
4. Редактирование товара НЕ списывает филамент: товар — шаблон/расчет, не факт производства.
5. Кнопка «Открыть в калькуляторе» переносит все параметры конкретного товара и его ID в калькулятор. Вверху явно покажи «Редактирование товара: <название>».
6. В этом режиме две разные операции: «Обновить товар» обновляет исходный товар строго по ID; «Сохранить как новый товар» создает новый товар-копию с новым ID.
7. При наличии несохраненных изменений предупреди при попытке уйти/закрыть режим редактирования.
8. Старые заказы никогда не пересчитывай после изменения товара.
9. Новая закупочная средняя цена филамента НЕ должна автоматически менять существующую retail/final price товара. Новый товар рассчитывается по текущей средней цене филамента. Существующий товар применяет новую расчетную цену только при явном пересчете/редактировании пользователя. Можно показать уведомление «Стоимость материала изменилась, пересчитать товар?» без автоприменения.
10. Отдельно от retail price учитывай фактический cost basis готового склада: новая единица, произведенная через +/«Произвести», должна получить себестоимость по актуальной средней стоимости филамента и другим текущим производственным параметрам на момент производства. Поддерживай weighted-average unit cost готового stock либо эквивалент через stock movements; это не должно автоматически менять цену каталога.
11. Убедись, что простое редактирование товара не меняет его stock_quantity и не создает складских движений само по себе.

Проверь совместимость с одиночными товарами и существующими assembly-товарами.
