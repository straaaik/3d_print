# Codex handoff package

Этот репозиторий содержит исходный проект без изменений бизнес-кода и дополнительный пакет инструкций для Codex.

Главная точка входа: `CODEX_START_HERE.md`.

Папка `docs/codex/` содержит:
- `00_MASTER_PROMPT.md` — все задачи одним проходом;
- `01_PHASE_...` – `06_PHASE_...` — рекомендуемая последовательность выполнения частями;
- `TASK_01.md` – `TASK_07.md` — автономные промпты по каждой пользовательской задаче;
- `DECISIONS_AND_CONSTRAINTS.md` — бизнес-решения и архитектурные ограничения;
- `ACCEPTANCE_CHECKLIST.md` — финальные проверки;
- `3d_labs_agent_tasks_report.html` — полный человекочитаемый отчёт.

Чтобы начать работу в Codex, загрузите репозиторий и отправьте в чат одну фразу:

> Прочитай `AGENTS.md` и `CODEX_START_HERE.md`. Выполняй работу по этапам в указанной последовательности, начиная с этапа 1. Не переходи к следующему этапу, пока текущий не доведён до целостного состояния. Git commit/push пока не делай.
